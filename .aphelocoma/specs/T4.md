# T4 — Remove the legacy context product

## Goal

Remove the second-brain/context runtime and unsupported adapters so the shipped repository contains
one product: the Hamilton agent crew.

## Scope

- Delete context, identity, knowledge, journal, registry, project-sync, web-view, and standalone helper
  skills outside Hamilton.
- Delete legacy adapter overrides/templates/hooks and the unsupported Cursor adapter.
- Remove obsolete shell/config paths and context-specific repository ignore entries.
- Add a package inventory test proving the removed runtime is absent.

## Non-scope

- Hamilton skill, roles, protocol, templates, examples, Claude/Codex crew assets.
- Historical design notes retained only as non-shipped project history.
- README/changelog narrative (T5).

## Interfaces / files touched

- `skills/*` except `skills/aph-hamilton/**`
- `adapters/claude-code/**` non-Hamilton legacy assets
- `adapters/codex/**` non-Hamilton legacy assets
- `adapters/cursor/**`
- `.gitignore`
- `tests/test_package_inventory.py`

## Acceptance criteria

- [ ] A package inventory test is written first and fails while any removed context skill, private
  knowledge export, journal hook, registry/view adapter, or Cursor support asset remains shipped.
- [ ] `skills/` contains only the Hamilton skill and its complete references/templates/examples.
- [ ] Claude/Codex adapters contain only assets required to deploy Hamilton and its crew safely.
- [ ] Cursor is absent from commands, runtime assets, and supported-target metadata.
- [ ] No removal touches `.aphelocoma/`, the advisor baseline commit, or `~/.aphelocoma/data`.
- [ ] The full test suite continues to pass after deletions.
