# T3 — Implement transactional lifecycle and deployment

## Goal

Make installation, update, deployment, undeployment, and uninstall reversible, ownership-aware, and
truthful for Claude Code and Codex without touching legacy data or unowned configuration.

## Scope

- Transactional install/update with staging, verification, atomic activation, and rollback.
- Per-tool deployment manifests, digests, backups, managed blocks, collision handling, and repeated
  deploy/undeploy behavior.
- Hamilton-only skill and crew generation for Claude Code and Codex; all 27 Codex roles generated.
- Safe v0.2 artifact detection and exact-match/proven-owned cleanup.
- Ownership-aware uninstall and PATH marker handling.
- Deployment/tool/legacy checks added to doctor.
- Failure-injection and isolated-home integration tests.

## Non-scope

- Changing Hamilton protocol/schema contracts finalized by T2.
- Deleting the legacy source tree itself (T4).
- Product documentation beyond command help (T5).

## Acceptance criteria

- [ ] Failing tests precede fixes for interrupted install, failed update/rollback, uninstall,
  deploy/undeploy twice, collision, corrupt manifest, block drift, both legacy path variants, and
  partial generator failure.
- [ ] Installer no longer invokes context setup and activates a verified tool atomically.
- [ ] Failed update restores the prior working tool; successful update retains a documented recovery
  point until completion.
- [ ] Deploy installs only Hamilton assets and generates the expected Claude/Codex crew; Codex produces
  27 parseable named roles.
- [ ] No command replaces an entire user `CLAUDE.md`, `AGENTS.md`, hooks file, or Codex config.
- [ ] Undeploy removes/restores only manifest-owned artifacts and reports modified drift without
  deleting it.
- [ ] Uninstall removes owned deployment/tool/PATH artifacts but never changes default/custom legacy
  data, backups, or unowned configuration.
- [ ] Doctor detects host readiness, sequential fallback, manifest/block drift, collisions, and legacy
  artifacts with tested exit codes.
