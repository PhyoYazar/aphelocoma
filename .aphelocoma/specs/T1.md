# T1 — Build the tested Python CLI and base doctor

## Goal

Replace the fragile monolithic Bash CLI with a Python 3.9+ standard-library CLI whose Hamilton-only
command surface, paths, errors, and base diagnostics are covered by isolated subprocess tests.

## Scope

- Python package and executable CLI entrypoint.
- Commands and help contracts for `deploy`, `undeploy`, `doctor`, `update`, `uninstall`, `version`,
  and `help`; later tasks fill lifecycle/deployment behavior behind those interfaces.
- Active `APHELOCOMA_ROOT` path model and read-only legacy `APHELOCOMA_HOME` warning.
- Atomic JSON/text helpers, base doctor checks, stable human/JSON output and exit codes.
- Tests for quoting, spaces/apostrophes, environment overrides, missing dependencies, and `NO_COLOR`.

## Non-scope

- Hamilton schema/migration checks (T2).
- Deployment manifests, installer/update/uninstall behavior, or tool readiness checks (T3).
- Deleting legacy source features (T4).

## Interfaces / files touched

- `bin/aph`
- `src/aphelocoma/__init__.py`
- `src/aphelocoma/cli.py`
- `src/aphelocoma/paths.py`
- `src/aphelocoma/io.py`
- `src/aphelocoma/doctor.py`
- `tests/__init__.py`
- `tests/test_cli.py`
- `tests/test_paths.py`
- `tests/test_doctor.py`

## Acceptance criteria

- [ ] Tests are written first and demonstrate failures for quoted/apostrophe paths, ignored
  `APHELOCOMA_HOME`, unstable/no-colour output, missing base diagnostics, and command/exit contracts.
- [ ] `python3 -m unittest` passes the T1 suite using isolated temporary homes.
- [ ] `bin/aph` runs with Python 3.9+ and imports no third-party packages.
- [ ] Only `APHELOCOMA_ROOT` controls active v0.3 storage; a set `APHELOCOMA_HOME` is reported as a
  protected legacy path and is never created or modified.
- [ ] Base doctor checks Python, Git, OS, installed version/definition completeness; supports
  human output and `--json`; returns 0 healthy, 1 actionable findings, 2 unexpected failure.
- [ ] Help exposes only the Hamilton-only command surface and contains no context/setup/add/sync/view
  behavior.
- [ ] Non-interactive output is readable without ANSI colour and respects `NO_COLOR`.
